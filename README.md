# DevOps Capstone Project

## Description

This repository contains the baseline code and implementation milestones for the CDAC PGCP-ITISS DevOps curriculum. The project progresses from version control and containerization to orchestration, monitoring, CI/CD, and infrastructure automation.

## Module Milestones

- **Day 01:** Git & GitHub Version Control (Windows Workstation)
- **Day 02:** Docker Containerization & Dockerfile Packaging
- **Day 03:** Multi-Container Stacks (Docker Compose) & Swarm Orchestration
- **Day 04:** Kubernetes Deployment Manifests & Prometheus Monitoring
- **Day 05:** Jenkins Automated CI/CD Pipelines
- **Day 06–10:** Infrastructure Automation (Terraform, Ansible, Chef, Puppet)

## Application

The baseline application is a Python HTTP server that serves a simple DevOps Microservice Portal on port `8080`.

## Project Goals

- Track source code and changes using Git and GitHub.
- Package the application in a Docker image.
- Deploy multi-container applications.
- Practise orchestration and monitoring.
- Automate builds and deployments with Jenkins.
- Explore infrastructure provisioning and configuration management.

## Getting Started

1. Install Python 3.
2. Run the application using `python app.py`.
3. Open `http://localhost:8080` in your browser.
4. Follow the module milestones to extend the application.
